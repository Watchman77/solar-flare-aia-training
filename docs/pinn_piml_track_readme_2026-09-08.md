# PINN/PIML Separate Track README

This track is designed to provide a clean, honest demonstration of physics-informed learning skill alongside the main solar-flare forecasting project.

## What this track is

- A portfolio/research-evidence track.
- A practical physics-informed ML prototype.
- A bridge between general PINN understanding and solar-flare-relevant representation learning.

## What this track is not

- Not a claim of full MHD simulation.
- Not a claim of causal solar-flare explanation.
- Not a replacement for the main multimodal temporal forecasting framework.

## Minimum viable completion

1. Complete `20A_pinn_foundation_heat_equation_demo.ipynb`.
2. Complete `20B_physics_informed_sharp_proxy_learning.ipynb`.
3. Generate one interview-ready figure and summary in `20C`.

## Strong phrase for CV/interview

> Developed a separate physics-informed machine learning prototype for space-weather forecasting, combining PINN foundations with SHARP-based auxiliary physical-proxy learning.
