# PINN/PIML Track Milestone Definition

## Milestone name

Separate Physics-Informed ML Evidence Track

## Purpose

Create an independent, defensible evidence package showing PINN/PIML capability in the context of space-weather forecasting.

## Minimum deliverable

- Foundation PINN demo completed.
- Solar proxy PIML prototype completed.
- Interview summary completed.

## Success definition

The user can honestly say:

> I have implemented a separate physics-informed ML prototype for solar/space-weather forecasting, including a PINN foundation demo and a SHARP-based auxiliary physical-proxy learning experiment.

## Scientific boundary

This is not a full MHD PINN and should not be presented as one.
