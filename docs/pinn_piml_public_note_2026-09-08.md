# Public Note: Separate PINN/PIML Track

This repository includes a separate planned PINN/PIML track in addition to the main multimodal flare-forecasting work.

The purpose is to demonstrate physics-informed machine learning capability in a carefully bounded way.

The track has two layers:

1. A simple PINN foundation notebook using a standard PDE demonstration.
2. A solar-flare-relevant physics-informed representation-learning prototype using magnetic proxy variables.

This track should not be described as a full magnetohydrodynamic solar-flare PINN unless the required plasma variables, governing equations, and boundary-condition formulation are explicitly implemented and validated.

Preferred description:

> A separate physics-informed machine learning prototype for space-weather forecasting, using auxiliary physical-proxy objectives and temporal-consistency regularisation.
