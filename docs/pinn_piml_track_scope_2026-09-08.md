- Simple PINN foundation notebook.
- Physics-informed SHARP proxy learning.

- Temporal consistency regularisation.
- Interview-ready explanation.

- Full MHD simulation.

- Claiming causal flare triggering.
- Expensive GPU experimentation.
- Replacing the main multimodal temporal forecasting sprint.

## Relationship to the main project

This track complements the main multimodal forecasting work by demonstrating an additional physics-informed modelling capability. It should remain separate unless later integrated through a controlled experiment.
