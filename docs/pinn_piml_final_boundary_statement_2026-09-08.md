# Final Boundary Statement for PINN/PIML Track

This statement should be reused in documentation, presentations, and interviews.

> This work explores physics-informed machine learning for solar/space-weather forecasting through a separate prototype track. It includes a standard PINN demonstration and a SHARP-based physics-informed representation-learning model using auxiliary physical-proxy losses. It should not be interpreted as a full magnetohydrodynamic PINN or a causal simulator of flare initiation. The goal is to show how physical domain knowledge can be incorporated into a forecasting model in a controlled and honest way.
