# PINN/PIML Minimum Viable Output

The minimum viable output for the separate PINN/PIML track is:

1. A completed PINN foundation notebook.
2. A completed SHARP proxy PIML notebook.
3. A single figure showing the combined loss structure.
4. A short result/lesson table.
5. An interview-safe summary.

This is enough to say the user has practical PINN/PIML exposure without claiming a full physical solar simulation.
