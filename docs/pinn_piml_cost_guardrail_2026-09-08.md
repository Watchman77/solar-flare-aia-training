# PINN/PIML Cost Guardrail

The separate PINN/PIML track is designed to be completed without paid GPU unless later justified.

## Rule

No Google Cloud GPU is required for the minimum viable PINN/PIML evidence track.

## Allowed execution

- Local CPU
- Local laptop
- Free/low-cost notebook environment
- Tiny capped runs only

## Not allowed without explicit decision

- Re-enabling billing just for PINN/PIML exploration
- Creating a persistent GPU VM
- Storing large intermediate data in paid cloud storage

## Reason

The PINN/PIML track is primarily a skill-evidence and portfolio track. It should support the main solar-flare paper without increasing cloud cost pressure.
